# 🚀 ShowCase

**ShowCase** is a Flask-based web application that allows developers and students to organize and showcase their code in one place.

Users can create an account, manage their profiles, and build their personal code collection.

## ✨ Features

* 🔐 User Registration and Login
* 👤 Personal Profile Management
* 📸 Profile Picture Upload
* 💻 Add and Save Code Snippets
* ✏️ Edit Existing Code
* 👀 View Saved Code
* 🗑️ Delete Code Snippets
* 🔍 Search Your Code Collection
* 🗂️ Support for Multiple Programming Languages
* 🗄️ SQLite Database

## 🛠️ Tech Stack

* **Backend:** Python, Flask
* **Frontend:** HTML, CSS
* **Database:** SQLite
* **Templating:** Jinja2

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd code_showcase
```

### 3. Install dependencies

```bash
pip install Flask Werkzeug
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000
```
